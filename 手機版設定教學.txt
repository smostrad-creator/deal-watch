手機查機票 設定教學
==================================
完成後：用手機打開查詢頁（跟電腦版一樣的畫面），按搜尋後，
GitHub 會幫你查，結果傳到 Telegram，查詢頁也會顯示完整比價表。電腦不用開。

需要先完成「特價快報」的設定（同一個 GitHub 專案、同一個 Telegram 機器人）。

────────────────────
第 1 步：上傳檔案（用電腦）
────────────────────
到 deal-watch 專案首頁 →「＋」→「Upload files」，把這些拖進去：
   ‧ 查機票.py
   ‧ 查機票網頁.py
   ‧ search_job.py
   ‧ docs 資料夾（整個資料夾拖進去）
按「Commit changes」。
上傳後首頁要看到「docs」資料夾，點進去裡面要有 index.html。

────────────────────
第 2 步：建立執行檔（.github 不能上傳，要用建立的）
────────────────────
專案首頁 →「＋」→「Create new file」
‧ 檔名輸入：.github/workflows/search.yml
‧ 內容：用記事本打開「search.yml內容.txt」，全部複製貼上
按「Commit changes」。

────────────────────
第 3 步：打開網頁空間（GitHub Pages）
────────────────────
專案的「Settings」→ 左邊「Pages」
‧ Source：選「Deploy from a branch」
‧ Branch：選「main」，旁邊資料夾選「/docs」→ 按「Save」
等 1～3 分鐘，重新整理這頁，上面會出現網址：
   https://你的帳號.github.io/deal-watch/

────────────────────
第 4 步：申請 GitHub 通行碼（token）
────────────────────
查詢頁要靠它叫 GitHub 開始查詢。
1. GitHub 右上角頭像 →「Settings」→ 左邊最下面「Developer settings」
2.「Personal access tokens」→「Fine-grained tokens」→「Generate new token」
3. 填寫：
   ‧ Token name：查機票手機版
   ‧ Expiration：選最長（例如 1 年），到期再申請一個新的
   ‧ Repository access：選「Only select repositories」→ 選「deal-watch」
   ‧ Permissions → Repository permissions，找到這兩個改成「Read and write」：
       Actions：Read and write
       Contents：Read and write
4. 最下面按「Generate token」
5. 複製出現的 github_pat_ 開頭那一串（只會顯示一次！先存到備忘錄）

────────────────────
第 5 步：手機設定
────────────────────
1. 用手機打開第 3 步的網址（iPhone 用 Safari）
2. 按右上角 ⚙️，貼上通行碼，帳號和專案名稱會自動填好 → 儲存
3. 加到主畫面：Safari 下方「分享」→「加入主畫面」，以後就像 App 一樣點開

────────────────────
第 6 步：測試
────────────────────
1. 選出發地、目的地、日期
2. 先勾「示範模式」（假資料，很快）→ 搜尋 → 確定搜尋
3. 約 1 分鐘後：Telegram 收到結果和 Excel，查詢頁也會顯示比價表
4. 成功後，取消「示範模式」，查真的機票

────────────────────
使用說明
────────────────────
‧ 按下搜尋後，可以關掉頁面，查完 Telegram 會通知你。
‧ Telegram 訊息裡的「打開完整比價表」，或查詢頁右上角「最近結果」，都能看最近一次的結果。
‧ 查詢時間：指定日期 1 組約 1～2 分鐘；區間 1 個月約 5～7 分鐘（GitHub 開機要 30 秒左右）。
‧ 一次只能查一個，上一個還沒查完，新的會排隊。
‧ 「■ 停止」會取消 GitHub 上的查詢。
‧ 通行碼只存在你手機的瀏覽器裡。換手機或清除瀏覽器資料，要重新貼一次。
‧ 查詢頁是公開網址，但沒有你的通行碼，別人打開也不能查詢。
